# EVE Planner

Веб-планировщик планетарной индустрии (PI) для EVE Online.
Статический сайт без бэкенда — вся логика на клиенте, данные хранятся в `localStorage` браузера.

**Адрес:** [sigetar.ru/eveonline](https://sigetar.ru/eveonline/)
**Репозиторий:** [SigetarWorld/eve-pi-planner](https://github.com/SigetarWorld/eve-pi-planner) (GitHub Pages)
**Лог изменений:** [sigetar.ru/log](https://sigetar.ru/log/)

---

## Назначение

Планировщик помогает управлять колониями PI нескольких персонажей EVE Online:

- выбрать планету, ресурс и цепочку производства;
- увидеть все колонии на карте региона;
- спланировать расстановку персонажей по планетам и ресурсам;
- просчитать маршрут прыжков капитального корабля;
- следить за складами колоний и их заполненностью;
- видеть живые цены PI-товаров по торговым хабам (Jita, Amarr, Dodixie, Rens).

Авторизация через EVE SSO (OAuth 2.0 + PKCE) подтягивает колонии, склады и навыки персонажей.

## Вкладки приложения

### Планеты

Карточки персонажей с их колониями. Аккаунт — линия, в ней до 3 карточек.
На карточке — 6 строк (планет): каскады «Регион → Система → Планета → P0 → P1», хаулер (Deluge / Epithal), дерево товаров колонии с количеством на складах.
Подсветка заполненности складов (пустой / 75 % / переполнен), процент заполнения в подсказке.
Масштаб карточек 100 / 90 / 80 %.
План (редактор) сравнивается с реальными колониями из ESI — статусы ✓ / ≠ / ✗ и «Вне плана»; кнопка ⟲ «Восстановить из EVE».

Справа — блок **Статистика**: сводные таблицы по P1 и P2 (ресурс, количество колоний, типы планет, где добывается, входы рецепта).

### Цепочки производства

Граф всех 83 PI-товаров (15 P0 → 15 P1 → 24 P2 → 21 P3 → 8 P4) с рецептами из SDE (68 схем из `planetSchematics.yaml`).
Фильтры по уровню; живые цены из ESI по выбранному торговому хабу; иконки типов планет, на которых добывается сырьё рецепта.

### Карты

Три режима, переключаются кнопками:

#### Планетарная карта

Майнд-карта региона: системы на координатах 2D из SDE, звёздные врата — линиями, пунктир — врата в соседние регионы.
От каждой системы — ветки по планетам (номер, тип) с их ресурсами.
Щелчок по типу в легенде подсвечивает системы с этим типом.
Масштабирование колесом мыши (вокруг курсора), перетаскивание, кнопки «+ − ⤢».
Для региона без данных о вратах (Exordium) системы раскладываются по кругу.
Бейджи уровня на ресурсах: тёмный фон, цветная рамка и текст (P0 — серо-синий, P1 — оранжевый, P2 — голубой).

#### Карта планирования

Планировщик колоний на карте региона.
Вокруг системы — её планеты (картинка и римский номер), вокруг каждой планеты — значки ресурсов выбранного уровня (P0 / P1 / P2) с картинками.
Клик по значку — модальное меню выбора персонажа. Имя персонажа пишется рядом со значком (снаружи).
Ограничение: не больше 6 планет на персонажа (как в игре).
Планеты и значки можно перетаскивать, кнопка ↺ возвращает раскладку.
«Скрыть пустые» — прячет планеты и ресурсы без записей в плане.
Бейджи уровня P0/P1/P2 в правом верхнем углу значка ресурса, в стиле планетарной карты.

Слева от карты — таблицы:
- **P1** — как в Статистике: ±, количество колоний, P1, типы планет, ввод.
- **P2** — то же для P2: входы рецепта, где собирается.

Модальное окно **«Персонажи»** — список персонажей с числом колоний.

#### Прыжковая карта

Планировщик прыжков капитальных кораблей по образцу Dotlan Jump Planner.
Правила прыжка — как в игре:
- дальность = база корабля × (1 + 0.2 × Jump Drive Calibration);
- топливо = расход × расстояние × (1 − 0.1 × JFC) × (1 − 0.1 × JF, у джамп-фрейтеров);
- прыжок только в лоу и нули (безопасность < 0.45); нельзя в Pochven, Jove, J-space.

Маршрут — наименьшее число прыжков, при равенстве — меньшее расстояние.
Панели (названия на русском):
- Jump Route — таблица маршрута (регион, система, sec, sov, убийства/прыжки за час);
- Jump Planner — добавление систем с подсказками;
- Waypoints — точки маршрута (перетаскивание, удаление);
- Jump Options — корабль и навыки (вручную или с персонажа);
- Avoid System/Region — обход систем и регионов;
- Jump Beacon Network — свои маяки, режим «только по маякам»;
- Load/Save Route — сохранённые маршруты и ссылка.

Карта маршрута сверху: связи систем — линиями, перелёты — дугами, подписаны системы и регионы.

### Мои колонии

Данные колоний с персонажей через ESI после входа.

**Склад** (модальное окно): планетарные ресурсы P0–P4 всех персонажей и контейнеров корпорации [Sigetar].
Карточки по аккаунтам, значки ангара / контейнеров / кораблей.
Вкладки:
- **Сводная таблица** — фильтры по P0–P4 и складам, уровни сворачиваются, штуки / объём / стоимость по хабу, тренд за 2 недели (▲/▼).
- **Планетарное имущество** — поиск и фильтры по P0–P4 с выбором ресурсов, сводная по центру.

Графики — компактный график на каждый уровень P0–P4, друг под другом, период до 30 дней, пропуски в данных соединены.

## Авторизация (EVE SSO)

Файл: `js/eveauth.js`.
Метод: OAuth 2.0 с PKCE (без `client_secret` — публичное приложение).
Redirect URI: `https://sigetar.ru/eveonline/`.
Scope:
- `esi-planets.manage_planets.v1` — колонии персонажа;
- `esi-assets.read_assets.v1` — активы персонажа;
- `esi-universe.read_structures.v1` — названия структур;
- `esi-assets.read_corporation_assets.v1` — активы корпорации;
- `esi-corporations.read_divisions.v1` — отделы корпорации.

Поддержка нескольких персонажей. Токены хранятся в `localStorage`.
Код подтверждения одноразовый, адресная строка чистится сразу.

## Источники данных

| Источник | Что берём | Примечание |
|----------|-----------|------------|
| **EVE SDE** (Static Data Export CCP) | Координаты систем (position2D), врата, типы планет, рецепты PI (planetSchematics.yaml — 68 схем), typeID товаров, данные кораблей | Данные вшиты в JS-файлы |

| **EVE SSO** | OAuth 2.0 + PKCE авторизация | Приложение на developers.eveonline.com |
| **images.evetech.net** | Иконки ресурсов PI | `types/{typeID}/icon` |
| **web.ccpgamescdn.com** | Официальная кнопка «LOG IN with EVE Online» | |

## Хранение данных в браузере

Всё пользовательское состояние — в `localStorage` (без серверного хранилища):

| Ключ (префикс `evepi.`) | Описание |
|--------------------------|----------|
| `eve` | Токены и данные персонажей EVE SSO |
| `lines` | Карточки персонажей (аккаунт-линии) |
| `plan.region` | Выбранный регион карты планирования |
| `plan.tier` | Уровень ресурсов (P0 / P1 / P2) |
| `plan.entries` | План колоний: `[{sys, num, type, res, tier, pilot}]` |
| `plan.panels` | Открытые панели карты планирования |
| `plan.hideUnused` | Флаг «Скрыть пустые» |
| `plan.pos.*` | Позиции перетащенных планет и значков |
| `mindmap.region` | Регион планетарной карты |
| `jump.*` | Настройки прыжковой карты: корабль, навыки, маршруты, маяки, обход |
| `warehouse.*` | Снимки складов и история |

## Версионирование

- **Версия стилей** — параметр `?v=` у `style.css` в `index.html` (сейчас `v=198`).
- **Версия JS-модулей** — параметр `?v=` у JS-файлов в `index.html` (сейчас `app.js?v=181`, `planmap.js?v=3` и т.д.).
- **Дата сборки** — константа `APP_BUILD` в `app.js`.
- Номера версий отображаются в шапке сайта (`#app-version`).
- При каждом изменении: увеличить `?v=` изменённого файла, обновить `APP_BUILD`, добавить запись в лог.
- **Лог изменений:** `E:\WebSite\Start\log\index.html` (на сайте — [sigetar.ru/log](https://sigetar.ru/log/)).
  Формат записи: краткое описание + `(vNNN · css vNNN)`.

## Технологии

- Чистый JavaScript (ES6+), без фреймворков и сборщиков.
- SVG для всех карт (планетарная, планирования, прыжковая).
- CSS Custom Properties для цветовой схемы (тёмная тема).
- Шрифты: **Orbitron** (заголовки), **Rajdhani** (данные), **Inter** (текст) — Google Fonts.
- ESI-запросы через `fetch` с CORS (`Access-Control-Allow-Origin: *`).
- OAuth 2.0 PKCE — авторизация без серверной части.

## Локальная разработка

```bash
cd eveonline
python3 -m http.server 8765
# Открыть http://localhost:8765/
```

Вход через EVE SSO работает только с `https://sigetar.ru/eveonline/` (redirect URI).
Локально доступны все функции кроме авторизации и загрузки данных с ESI, требующих токен.

## Цветовая схема бейджей уровня

Единый стиль на всех картах (CSS-класс `mm-tier` / `pm-tier-sq` / `ct-tier`):

| Уровень | Фон | Рамка | Текст |
|---------|-----|-------|-------|
| P0 | `rgba(255,255,255,0.07)` | `rgba(150,185,230,0.55)` | `var(--text-dim)` |
| P1 | `rgba(255,157,46,0.14)` | `rgba(255,157,46,0.8)` | `var(--accent)` |
| P2 / P3 | `color-mix(in srgb, var(--cyan) 14%, #0b1220)` | `color-mix(in srgb, var(--cyan) 80%, transparent)` | `var(--cyan)` |
