// Style — иконки

Иконки сайта

Все иконки, найденные на страницах sigetar.ru. Каждая лежит отдельным SVG в папке Style\icons; откуда она взята и где используется — в icons.json. Стандарт: сетка 24×24, только контур, линия --icon-stroke (1.8), скруглённые концы. Рамкой янтарного цвета отмечены иконки, которые ему не соответствуют.
