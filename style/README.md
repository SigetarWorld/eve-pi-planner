# Общий стиль sigetar.ru

Папка `E:\WebSite\Style` — единственный источник оформления для всех страниц.
При публикации (`publish.bat`) и просмотре (`preview.bat`) она выкладывается как `/style/`.

## Как подключить к странице

```html
<head>
    <link rel="stylesheet" href="/style/site.css?v=2">
    <!-- стили только этой страницы — после общего -->
</head>
<body>
    <script src="/style/layout.js?v=1"></script>   <!-- шапка, подвал, фон плиток -->
    <main> … </main>
</body>
```

Шрифты подключать не нужно — их подключает `site.css` (или `app.css`).
Приложение со своими компонентами подключает `/style/app.css` вместо `site.css`, а свои переменные определяет через токены: `--accent: hsl(var(--primary));` — так сделано в EVE Planner.
После правки файлов стиля увеличь `?v=` в `site.css` (у тех файлов, что поменялись) и на страницах — иначе браузеры покажут старую версию из кэша.

## Файлы

| Файл | Что внутри |
|---|---|
| `tokens.css` | все цвета, шрифты, размеры, свечение — **единственное место, где они задаются** |
| `base.css` | сброс, фон (градиент, звёзды, сканлайны), текст, контейнер, `main`, скроллбар |
| `layout.css` | общая шапка и подвал |
| `components.css` | заголовки разделов, плитки, строки-списки, факты, теги, кнопки, ссылки на каналы |
| `site.css` | вход для **страниц**: шрифты + tokens + base + layout + components |
| `app.css` | вход для **приложений** (EVE Planner): шрифты + tokens + base + layout, без components — у приложения свои `.panel`, `.btn`… и чужие им мешают |
| `layout.js` | вставляет общую шапку и подвал, подсвечивает текущий раздел, раскладывает общую картинку по ряду плиток |

## Правила

1. **Цвета — только через токены**: `hsl(var(--primary))`, `hsl(var(--card) / .7)`. Никаких `#ff9d2e` и `rgba(…)` на страницах. Нужен новый цвет — добавь токен в `tokens.css`.
   Исключение — фирменные цвета сервисов (YouTube, VK…) в логотипах.
2. **Шрифты — четыре, через токены**:
   `--font-display` (Orbitron) — крупные заголовки и логотип;
   `--font-heading` (Rajdhani) — подзаголовки, меню, подписи;
   `--font-body` (Inter) — основной текст;
   `--font-mono` (Share Tech Mono) — даты, цифры, служебные надписи.
3. **Углы квадратные** — `border-radius` не задаём (или `var(--radius)`, он равен 0). Круги (`50%`) — только для точек-индикаторов.
4. **Меню сайта правится только в `layout.js`** (список `SITE_NAV`). На страницах своей шапки нет.
5. **Без размытия фона** (`backdrop-filter`) и без `background-attachment: fixed` — от них страница мигает при прокрутке.
6. Если компонент нужен на двух страницах и больше — он переезжает в `components.css`. Стили одной страницы живут рядом с ней.

## Цвета состояний

| Токен | Значение |
|---|---|
| `--success` | выполнено, онлайн, прибыль |
| `--warning` | в работе (тот же янтарь, что `--primary`) |
| `--danger` | ошибка, недоступно, убыток |
| `--info` | справка, подсветка схем |
| `--rare` | редкое / эволюция |

## Готовые компоненты

- Раздел: `<p class="eyebrow">// 01 — Название</p>`, `<h2 class="section-title">`, `<p class="section-lead">`, разделитель `<hr class="rule">`.
- Ряд плиток: `<div class="grid">` + `<div class="panel">`, заголовок плитки `<h3 class="h-split">Название <span>подпись</span></h3>`.
- Общая картинка на ряд: `<div class="grid grid--shared-bg" style="--shared-img: url('/img/….jpg')">` + плитки `panel panel--shared`.
- Строки «название — значение»: `<ul class="ships">` → `<a class="ship">` с `ship-img ship-img--glyph`, `ship-name`, `ship-val` / `ship-kills`.
- Кнопки: `.btn`, `.btn--teal`, `.btn--sm`; группа — `.actions`.
- Ссылки на каналы: `.stats.stats--social` + `.stat.stat--logo`, донат — `.stat--donate`.

## Иконки — `icons/`

Все иконки сайта собраны в `icons/`, по одной в SVG-файле. Обзор со всеми иконками сразу: `icons/index.html`
(локально — `http://localhost:8000/style/icons/` через `preview.bat`). Откуда взята каждая и где используется — `icons/icons.json`.

| Папка | Что |
|---|---|
| `icons/` | общий набор контурных значков: главная, категории Valheim, боссы и биомы Valheim, значки канала. Если рисунок с таким именем уже был — новый назван `nb-…` |
| `icons/brands/` | логотипы сервисов (YouTube, Rutube, VK, Telegram, Boosty) |
| `icons/eve/` | значки EVE Planner (сегменты маршрута, склады, кнопки карточек и карты, плашки ISK / 24ч / PLEX) |
| `icons/art/` | иллюстрации (викинг на дорожной карте Valheim) |

**Стандарт значков:** сетка 24×24, только контур, толщина линии `--icon-stroke` (1.8, в `tokens.css`), скруглённые концы и углы.
На странице значок — это `<svg class="icon" viewBox="0 0 24 24">…</svg>` (на главной — класс `glyph`): правило `svg.icon` в `base.css`
задаёт контур, толщину и концы, поэтому поменять стиль всех значков сайта можно одной строкой в `tokens.css`.
Новый значок рисуем по стандарту и кладём в `icons/`. Логотипы сервисов (`brands/`) и иллюстрации (`art/`) — исключения, их не перерисовываем.
